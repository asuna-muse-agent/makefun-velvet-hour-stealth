VELVET HOUR — The Gullwing Gallery Heist. A top-down stealth game: you are Wren, a thief slipping through the Gullwing Gallery after closing. Steal the artifacts, reach the skylight exit unseen. Three galleries, five named guard types plus the boss Curator Voss, vision cones, lamp light and shadow, noise rings, suspicion with recovery, Ghost bonus and S/A/B/C ranks.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD / arrows move, SHIFT runs (loud!), P pauses, M mutes, R restarts.
